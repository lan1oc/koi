# 模型请求恢复与原通报读取

Agent 规划、对话、继续入口和证据判定共用模型故障恢复。模型连接失败、服务限流、流式响应中断时，保留当前文件、阶段、证据和工具结果，重试同一份模型输入。当前配置不可用时，按保存顺序尝试其他配置完整的模型。成功切换用于当前调查，不改动设置页选中的配置；可取消的会话请求在停止后不会再发出后续重试。

连续无进展的工具计划会自动进入证据整理阶段，轮换模型并要求逐项判定。已完成的请求继续复用，不通过重复发出目标请求来恢复。所有配置均失败或恢复后仍无进展时，保留可继续的断点并显示失败原因。不会无限重试，也不会把证据不足视为修复成功。

兼容接口把完整累计思考放进增量字段时，客户端只追加新增后缀。重复生成同一段推理且迟迟没有决定时，会终止该次生成并尝试恢复。该机制依据实际文本重复情况，不恢复固定的 240 秒生成时限。

Word 读取包含正文、表格和超链接，也会用 Windows 本机 OCR 读取内嵌 PNG、JPEG、BMP 截图。图片不上传到外部服务，原文件保持不变。识别文字有明确来源标记；缺少 OCR 语言或无法识别时，返回具体缺口。单张图片最多 8 MiB，每份文件最多识别 16 张；超过范围的内容会明确标记未读取。重复读取相同截图使用进程内缓存。

`read_evidence` 的路径相对于证据的 `data`，空路径读取根，也接受 `/data` 前缀。摘要里的 `excerpt` 并非原始字段，读取工具会解析相应的原始字符串。无效路径返回可用字段，帮助模型修正调用。Python 探针保留更长的响应片段，并明确记录截断；分页读取证据本身不会再发出目标请求。

思考区使用独立的滚动跟随：生成时显示最新内容，上滚时暂停跟随，点击“回到底部”后恢复。外层会话和内层思考区分别控制。
